## 1. WHAT — What This Document Defines

This document records a clean-room release rehearsal for the `v0.1.5` candidate.

It is not a version bump, tag, or GitHub Release. It checks whether the small `v0.1.5` candidate changes are meaningful enough to freeze later as a patch release: first-user documentation polish, `bundle-summary` scenario clarity, and the more general human-readable bundle-summary title.

## 6. WHY — Background Judgment

`v0.1.5` is not about adding capability. Its value is reducing first-reader ambiguity after the `v0.1.4` release quality baseline: feedback intake labels stay current, bundle-summary scenario usage is easier to follow, and bundle handoff wording no longer sounds sampled-only.

The source archive smoke also found and fixed a release-process issue: clean-room release quality smoke should work outside a Git worktree when the repo is archived for external-user rehearsal.

## 7. LEARNED CAUTIONS — Learned Cautions

- Clean-room source archives are not Git worktrees; release smoke scripts should not assume `git diff --check` can run there.
