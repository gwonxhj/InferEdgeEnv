## 6. WHY — 배경 판단

`v0.1.4` 후보의 가치는 새 feature 추가가 아니라 품질 기준선 고정이다. The local release quality smoke now covers the core evidence loop: record evidence, reject corrupt evidence, preserve diagnostics, compare honestly, move bundles safely, and summarize handoff output without ranking.

This closes the six-month quality roadmap as a repeatable release baseline while keeping Jetson sampled evidence optional and hardware-gated.
