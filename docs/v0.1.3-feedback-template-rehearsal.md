# EdgeEnv v0.1.3 Feedback Template Rehearsal

## 1. WHAT — 이 문서가 정하는 것

README의 `Start Here for v0.1.3` 경로를 새 사용자 관점으로 다시 실행하고, `.github/ISSUE_TEMPLATE/readme-quickstart-feedback.md`가 실제 질문을 충분히 받을 수 있는지 확인한 기록이다.

이 문서는 새 기능 설계가 아니다. Quickstart 실행 결과와 가상의 feedback issue 샘플을 통해 template 질문이 너무 많거나 빠진 항목이 있는지 점검한다.

## 2. CONTENTS — 실행한 사용자 흐름

Commands rehearsed from the README path:

```bash
python -m inferedge_env.cli doctor
edgeenv doctor
edgeenv profile validate examples/profiles/local_fake.yaml
edgeenv bench validate examples/benches/yolov8n_fire.yaml
edgeenv bench run --target examples/profiles/local_fake.yaml --config examples/benches/yolov8n_fire.yaml
edgeenv runs list
edgeenv runs show <run_id>
edgeenv bench run --target examples/profiles/local.yaml --config examples/benches/local_echo_metrics.yaml
edgeenv bench run --target examples/profiles/local.yaml --config examples/benches/local_resource_metrics.yaml
edgeenv runs resources list --metric memory_peak_mb
edgeenv bench run --target examples/profiles/local.yaml --config examples/benches/local_compare_a.yaml
edgeenv bench run --target examples/profiles/local.yaml --config examples/benches/local_compare_b.yaml
edgeenv report compare <run_id_a> <run_id_b>
```

Observed:

- Both doctor entrypoints reported `Version: 0.1.3`.
- Fake profile/config validation passed.
- Fake run stored `result.json` and reported deterministic latency.
- Local command run stored metrics; resource example stored supplemental resource evidence.
- Resource query printed source and unit.
- Compare printed `Comparable: Yes`, `Mode: same-condition`, protocol reasons, then metric deltas.

## 3. HOW — 가상 feedback issue 샘플

### Sample 1 — Run ID Copy Step

Title:

```text
[feedback] README quickstart: run_id handoff was not obvious
```

Starting Path:

- Fake run

First Confusing Step:

```bash
edgeenv runs show <run_id>
```

What happened?

```text
The previous command printed a concrete run ID, but I was not sure whether README expected me to copy it manually from "Benchmark run stored" or get it from "edgeenv runs list".
```

Expected Help:

```text
A short sentence saying "Use the Run ID printed by bench run or copy it from edgeenv runs list" would make the placeholder clearer.
```

Environment:

- OS: macOS
- Python version: local dev Python
- Install command: editable install
- EdgeEnv version from `edgeenv doctor`: `0.1.3`
- Execution path: fake

Template verdict:

- The template captures this well. No template change needed.
- Potential future README wording improvement if repeated by real users.

## 4. HOW NOT — 피해야 할 함정

- Do not create real GitHub issues for rehearsal-only samples.
- Do not turn sample feedback into implementation work until repeated real feedback appears.
- Do not change compare output wording from a hypothetical concern alone.
- Do not add new issue labels unless the repository label set is intentionally managed.

## 5. WHERE — 다음에 반영할 위치

If real users repeat the same confusion:

- Run ID handoff: README Quickstart wording near `runs show <run_id>`
- Resource metrics meaning: README "Optional Resource And Sampler Evidence" or `docs/resource-query-rehearsal.md`
- Compare delta interpretation: `docs/compare-workflow-guide.md`
- Template wording: `.github/ISSUE_TEMPLATE/readme-quickstart-feedback.md`

## 6. WHY — 배경 판단

The template is intentionally small. It asks for the starting path, first confusing command, observed output, expected help, and environment. The rehearsal suggests that is enough to triage first-user friction without inviting broad feature requests.

The strongest signal should remain the first blocked path, not a speculative feature list.

## 7. ⚠️ LEARNED CAUTIONS — 학습된 주의사항

- Rehearsal feedback samples should document possible user confusion without creating real issues or changing product scope.
